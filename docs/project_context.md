# Project Context - Eye_Tracking_2.0

## Overview
- This is an eye tracking project focused on extreme speed and performance, without requiring a powerful device to run.
- This is for anyone with hand or wrist pain using a mouse. This aims to solve the issue of having to constantly move your hand on and off the keyboard to use the mouse. Ideally, you would simply keep your hands on the keyboard without having to move them off it.

## Goals
- Have a basic functional prototype that can be further optmized and refined for better performance.
- For this stage of the project, "done" means a basic functional prototype that allows you to move the mouse with your eyes.

## Tech Stack
- Language: Python 3.13
- OS: Windows 11

- Tools: VS Code, Git

## Constraints & Prefrences
- All code should have simple, clear comments explaining what each line does.
- Keep the coding as simple as possible
- It needs to be as performant, responsive, and fast as possible.
- Avoid extreme complexity that would slow things and make it hard for any device to run the program
