# Project Context - Eye_Tracking_2.0

## Overview
- This is an eye tracking project focused on extreme speed and performance while not needing a powerful device to run
- This is for anyone with hand or wrist pain using a mouse. This aims to solve the issue of having to continously use your hand on and off the keyboard to use the mouse. Ideally, you would just keep your hands on the keyboard without having to move your hands off the keyboard.

## Goals
- Have a basic functional prototype that can be further optmized and refined for better performance.
- Done for this stage of the project looks like a basic functional prototype that allows you to move the mouse with your eyes.

## Tech Stack

- Tools: VS Code, Git

## Constraints & Prefrences
- Every code has simple and clear comments to explain what that line does
- Keep the coding as simple as possible
- Needs to be as performant as possible, needs to be responsiveness and fast as possible
- Avoid extreme complexity that would slow things and make it hard for any device to run the program
